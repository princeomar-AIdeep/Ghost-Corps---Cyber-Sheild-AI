CYBER-AGENT AI — Dashboard Assets

Contents:
- dashboard-reference.png: full dashboard screenshot; use as the visual source of truth.
- cyber-agent-logo-reference.png: exact logo crop from the supplied screenshot. If the original standalone logo file exists in your project, prefer that file for production.
- hero-cyber-agent-city.png: high-resolution newly generated hero illustration in the same dark cyan cyber-operations style.
- ai-assistant-avatar.png: high-resolution newly generated assistant character portrait.
- digital-globe-network.png: high-resolution newly generated globe/network illustration.
- hero-reference-crop.png, assistant-avatar-reference-crop.png, globe-reference-crop.png: crops from the screenshot for matching composition only; these are not intended as final high-resolution assets.

Suggested use:
- Put these files in your project's public/assets/ directory.
- Reference them with paths such as /assets/hero-cyber-agent-city.png.
- Use dashboard-reference.png only as a visual comparison reference, not as a page background.
- The generated images are visual replacements in a matching style, not guaranteed pixel-identical copies of the original screenshot art.
